## How to Run the Program

1. Open the project in Eclipse.
2. Open `GPUApp.java`.
3. Run `GPUApp.java` as a Java application.
4. Log in using one of the accounts below.

The program loads its data from these files in the project folder:

- `students.txt`
- `requests.txt`
- `grants.txt`
- `jobs.txt`
- `clock.txt`

The program saves changes to these files after actions such as submitting or cancelling a job.

## Resetting the Data

A copy of the original data is stored in the `sample_data` folder.

To reset the program:

1. Close the program.
2. Copy the five `.txt` files from `sample_data`.
3. Paste them into the main project folder.
4. Replace the existing files.
5. Run `GPUApp.java` again.

`TestData.java` can also recreate the sample data from the beginning.
